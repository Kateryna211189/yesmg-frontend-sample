# YESMG Front-End Sample

This is a small front-end sample demonstrating:

- clean HTML/CSS structure  
- responsive layout (desktop + mobile)  
- corporate-style design  
- lightweight implementation without frameworks  

## Django Integration

The structure is designed to integrate into a Django project:

- base template structure  
- reusable header/footer partials  
- block-based page composition  
- static asset organization
